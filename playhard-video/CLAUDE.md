# PlayHard — видео для кейса unitodi.ru

Эта папка — набор для плавных 60 fps скринкастов сайта. Сессия Claude Code запущена на компьютере пользователя,
поэтому сайт https://unitodi.ru открывается напрямую (из облачной сессии он был недоступен).
Отвечай пользователю по-русски, коротко.

## Задача (из созвона с Сабриной)

Сабрина собирает в Figma страницу кейса. Тексты, картинки и подложки готовы; наша часть — **видео живого сайта**.

Требования:
- только дизайн сайта, без своего моушен-дизайна;
- **плавно**: первая версия (запись экрана, 30 fps) отклонена — «дёргается скролл», «нет фона подложки»;
- лёгкие файлы без потери качества;
- вставка в её слоты 1200×600, экран внутри слота на подложке.

| # | Ролик | Что показать |
|---|---|---|
| 1 | Главная, ~30 с | загрузка сайта и прелоадер → первый экран → наведение на меню → наведение на «Программное обеспечение» → немного интерактива → скролл главной |
| 2–4 | «3D и анимация» | три анимированных / 3D-блока сайта, каждый отдельным роликом (`compose.crop`), желательно бесшовный цикл |
| 5 | Схема «О компании» | схема реагирует на наведение; показать три анимированных элемента |
| 6 | Карточка ПО | движущаяся карточка на странице ПО |
| 7 | (по желанию) поворот устройства | уточнить блок у пользователя |

Эталон стиля — прошлые кейсы play-hard.agency/portfolio/{russkiy-sever, rhinoil, flat-interior}.

## Почему так снимаем

Не записывай экран и не управляй видимым Chrome (computer use) — это реальное время, будут рывки.
`capture.mjs` запускает chrome-headless-shell с begin-frame control и подменяет часы страницы:
- каждый кадр время сдвигается ровно на 1/60 с;
- CSS-анимации, rAF, таймеры, `performance.now`, `Date` и `<video>` идут по этим часам;
- пока грузятся запросы, часы стоят — картинки и шрифты не «выпрыгивают».

Результат — идеальные 60 fps при любой скорости компьютера. Курсор дорисовывает `compose.mjs` по записанной траектории.

## Первый запуск (Windows)

1. `node -v` — нужен Node.js 18+. Если его нет: `winget install OpenJS.NodeJS.LTS`, затем перезапусти терминал.
2. `npm install` — puppeteer-core и ffmpeg (ffmpeg-static, отдельно ставить не нужно).
3. `npm run setup` — скачает chrome-headless-shell 141 в `browsers/`.
4. `npm test` — самопроверка на тестовой странице. Результат: `out/test-draft/preview.html`, ~1–2 мин.

## Ролик 1 — главная

1. **Разведка:** `node probe.mjs https://unitodi.ru/`. Прочитай `probe/unitodi.ru/report.json` и посмотри картинки:
   - `load-*.png` — как идёт загрузка и прелоадер;
   - `hover-*.png` — реакция меню;
   - `scroll-*.png` — экраны вниз по странице.
2. **Сценарий** `scenarios/01-home.json`, подстроить по отчёту:
   - **Меню** (`hover`): `navItems` в отчёте. Если «Программное обеспечение» в подменю, сначала `move` на родителя, `wait`, потом `move` на пункт.
   - **Лишние слои** (`hide`): селекторы cookie-баннера и чата из `fixed`.
   - **Скролл** (`scrollKind`):
     - `native` — `scrollMode: "wheel"`, это работает и для Lenis;
     - `transform` — wheel, длину задавать `scroll.by`;
     - «колесо не скроллит» — fullpage/слайды: шаги `scroll` с `by` на высоту экрана и паузами.
   - **Свой курсор на сайте** (`customCursor: true`): `compose.cursor: false`, иначе курсоров будет два.
   - **Тяжёлый WebGL**, и съёмка идёт < 3 кадр/с: `"gpu": true`.
   - **Длина ~30 с:** `tour.until` (px), меньше `dwell`, или явные `scroll`.
3. **Черновик:** `node make.mjs scenarios/01-home.json --draft`, 1×, быстро.
   - Достань кадры в моменты из таймлайна (его печатает съёмка):
     `node_modules\ffmpeg-static\ffmpeg.exe -ss 5 -i out\01-home-draft\screen.mp4 -frames:v 1 out\check-5s.png`
   - Посмотри кадры. Проверь, что прелоадер виден целиком и наведения попали в пункты.
4. **Чистовик:** `node make.mjs scenarios/01-home.json`.
   - Количество кадров: `node_modules\ffmpeg-static\ffmpeg.exe -i out\01-home\01-home.webm -map 0:v -f null -` → `frame=` должно быть ≈ длительность × 60.
   - Застывание при движении: фильтр `freezedetect`. Застывать можно только на паузах `wait`.
   - Открой превью: `start out\01-home\preview.html`.
5. **Отчёт пользователю:**
   - длительность, вес WebM/MP4, что показано;
   - попроси у Сабрины подложку слота PNG @2x и координаты экрана в слоте (x, y, ширина, высота, скругление), чтобы собрать финал на подложке.

## Сборка на подложке

Блок `compose` в сценарии:
- `bg` — PNG подложки, путь от папки сценария;
- `size` — `"1200x600"`;
- `scale` — `2`;
- `rect` — `"x,y,w,h"` экрана в слоте, в px макета;
- `radius`;
- `cursor`;
- `crop` — `"x,y,w,h"` в CSS px окна, только для отдельного блока;
- `clean` — дополнительно чистый экран без подложки.

`viewport` подбирай по пропорциям `rect` (`w/h`), иначе картинка растянется — `compose` предупредит.
Пересобрать без пересъёмки: `node make.mjs scenarios/01-home.json --compose`.

## Шаги сценария

Шаги идут по очереди. `"with": true` запускает шаг вместе с предыдущим, `"pause": сек` задаёт паузу перед шагом.

| Шаг | Что делает |
|---|---|
| `goto` | переход на `url` |
| `waitFor` | `preloader: true` (ждёт, пока уйдёт полноэкранный fixed-слой), `selector` или `js`; есть `timeout` |
| `wait` | пауза `sec` |
| `move` | мышь `to`: `[x,y]`, `"text:…"` или `"selector:…"`; плюс `dur`, `ease`, `offset` |
| `hover` | по очереди навести на пункты: `targets: "nav"` или список, `dwell`, `max`, `skip` |
| `scroll` | `by` px, или `to: "end" / "top" / "text:…"`, или `toY`; плюс `speed`, `dur`, `maxDur`, `mode: "wheel" / "native"` |
| `tour` | проход по секциям с паузами: `sections` (CSS), `dwell`, `speed`, `until` |
| `click` | клик в текущей точке или `to` |
| `eval` | выполнить JS на странице |

Кривые: `linear`, `inOutSine`, `inOutCubic`, `outCubic`, `inOutQuint`.

Поля верхнего уровня:

| Поле | Что задаёт |
|---|---|
| `viewport`, `scale` | окно; `"auto"` — плотность под выход |
| `startAt` | секунды в начале, которые не сохранять |
| `duration`, `maxDuration`, `tail` | длина записи |
| `hide`, `css` | что скрыть или переопределить на странице |
| `block`, `blockDefault` | какие запросы блокировать (аналитика и чаты блокируются по умолчанию) |
| `netWait`, `syncVideo`, `gpu`, `headers`, `cookies` | ожидание сети, видео на странице, GPU, доступ к закрытым страницам |

## Если что-то не так

- **Прелоадер не определяется** (`waitFor timed out`) → `waitFor` с `selector` элемента первого экрана или `js`.
- **Анимация зависла.** Сайт мог считать время в Web Worker (часы не подменяются) или по аудио. Посмотри, на чём он построен, и предложи пользователю обход.
- **Видео на странице не играет** → проверь `h264` в отчёте probe. Chrome for Testing играет H.264.
- **Медленно.** Уменьши `scale` или `viewport`, включи `"gpu": true`.
- **Не коммить** `out/`, `probe/`, `browsers/`, `node_modules/` — они в `.gitignore`.
